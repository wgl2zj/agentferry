# Ticket 04：解包引擎（applier）+ 路径适配（pathfix）

Status: done
Type: task

## 目标

纯 Rust 模块：读 `.zam` 校验（manifest 解析、format_version、逐文件 SHA-256）→ dry-run 计划（四组：新增/一致/冲突/目标保留；增量模式冲突默认保留目标）→ 确认后执行（备份 → 写入 → 复验）→ 验证报告；pathfix 检出文本资产旧机绝对路径并按用户映射替换（UTF-8 无 BOM 保持）。

## 验收

- [ ] 读包校验：篡改包内一个文件后校验失败并列出差异文件
- [ ] dry-run 四组归类正确（构造：包内 3 文件分别对应目标缺失/相同/不同；目标多 1 文件）
- [ ] 反向测试：dry-run 未确认执行时，目标目录零变化（字节级对比）
- [ ] 覆盖模式：冲突文件先备份至 `zam-backups/<时间戳>/` 再替换；备份文件与原文件字节一致；备份目录保留最近 5 次，超出时执行前返回"建议清理"提示（不静默删）
- [ ] 增量模式：冲突默认保留目标；逐条改判后按替换执行
- [ ] 反向测试：执行前后目标侧原有文件集合不减（无删除）
- [ ] 执行后逐文件复验哈希；构造一个"写入后内容不符"场景断言立即停止并报告
- [ ] pathfix：文本含 `C:\Users\old\` 映射替换后内容正确、无 BOM 引入（字节级断言）；含 BOM/非 UTF-8 文件跳过并出警告；替换前该文件走备份
- [ ] 两模式均不删目标文件（同上反向测试覆盖）
